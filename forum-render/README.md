# 百无禁忌社区：Render 免费试用版

“生活那点事”板块现改名为“编辑那点事”，已有帖子由增量迁移保留。旧板块链接兼容新名称。登录后点击右上角昵称，可在“我的社区名片”上传或更换头像、修改昵称并点击“保存资料”。头像自动居中裁成方形；支持 JPG、PNG 和 WebP，原图最大5MB。服务端再次校验并转成256像素 JPEG，保存在 PostgreSQL 中，重启不会丢失。头像显示于导航、帖子列表、主帖和回复；修改后旧内容同步显示新头像。可以恢复默认猫咪头像。

马卡龙猫爪界面、兴趣板块、搜索、匿名浏览、发帖、引用回复、点赞、收藏、用户名密码注册、登录、找回码及昵称管理均已移植。前端和 API 在独立 Node 服务内运行，不代理原站，不依赖 chatgpt.site。

## 免费部署

使用 Render 免费 Web 服务和独立免费 PostgreSQL 数据库。数据库不会随 Web 服务重启丢失，但 Render 免费数据库只有 30 天有效期。免费 Web 服务闲置 15 分钟后会休眠，下次打开可能等待约 1 分钟。免费额度用尽后服务可能暂停，后续升级需要另行决定。

代码位于 paw-library 的 baiwujinji-render 分支、forum-render 目录，main 分支资料站保持原样。分支根目录 render.yaml 仅创建新的免费社区服务，通过 fromDatabase 引用已存在的 baiwujinji-community-free-db 免费数据库，不创建收费磁盘或收费数据库。

构建命令：`npm ci --no-audit --no-fund && npm run build`。启动命令：`npm start`。健康检查：`/healthz`。DATABASE_URL 由 Render 内部注入，不写入源码。

## 数据迁移

原站数据经私密运行环境变量 MIGRATION_SNAPSHOT 导入，整个导入在一个事务中执行，只执行一次。数据库初始化在端口监听前完成。保留账号密码摘要、作者 ID、帖子、回复、收藏、点赞，不复制旧登录会话。不得把数据库备份、连接串、密码摘要、找回码或会话令牌提交到公开仓库。

旧 ChatGPT 登录身份不能在新站直接登录；普通用户名密码账号可以保留密码继续登录。原站旧内容仍可浏览，新发内容需要在新站免费注册。切换时应检查原站最终快照，避免遗漏迁移窗口的新内容。

## 验证

本地使用实际 PostgreSQL 引擎 PGlite 验证 PostgreSQL 兼容性及重启持久化，也保留 SQLite 本地开发路径。测试覆盖匿名浏览、注册、发帖、回复、收藏、点赞、跨站拒绝、重启后数据和会话保留、退出、重新登录和找回密码。上线后仍需实际手机微信测试访问。

```sh
npm ci
npm run build
npm test
TEST_PG=1 npm test
```

线上启动必须有 DATABASE_URL；禁止将 Render 免费服务的临时本地 SQLite 作为用户数据库。SQLite 路径在 Render 中仍会拒绝未验证的磁盘。
