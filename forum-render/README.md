# 百无禁忌社区：独立 Render 运行版本

已移植原有马卡龙猫爪界面、兴趣板块、搜索、发帖、引用回复、点赞、收藏、用户名密码注册、登录、找回码及昵称管理。匿名可浏览。前端和 API 均在独立 Node 服务内运行，不代理原站，不依赖 chatgpt.site。

## 当前状态

本版本已通过本地编译和真实 HTTP 集成测试。测试覆盖匿名浏览、注册、发帖、回复、收藏、点赞、跨站请求拒绝、重启后数据和会话保留、退出、重新登录、密码找回及密码摘要存储。测试使用独立临时数据库，不修改线上内容。

尚未开通收费资源、切换网址或导入线上数据库。准备配置按新加坡区域的最小付费 Web 服务加 1GB 持久磁盘计算：基础费用约 US$7.25/月，税费及超额用量另计，以 Render 实际账单为准。不能保证任何托管平台在所有网络和微信客户端均可访问，上线后仍需手机实测。

## 部署

代码保存在 paw-library 的 baiwujinji-render 分支，forum-render 目录。分支根目录的 render.yaml 仅定义新的 baiwujinji-community 服务。现有 main 分支的资料站不受影响。

确认费用后，在 My Workspace 中使用本分支的 Blueprint 创建服务和持久磁盘。构建命令为 `npm install --no-audit --no-fund && npm run build`，启动命令为 `npm start`。磁盘挂载 `/var/data`，数据库路径为 `/var/data/forum.sqlite`，健康检查为 `/healthz`。应用在 Render 上检测不到磁盘时会拒绝启动，避免静默把用户数据写入临时目录。

启动后先导入原站完整数据库备份，再开放发帖。原站备份必须通过私密传输导入，禁止提交到公开 Git 仓库。保留用户 ID、账号密码摘要、帖子、回复、收藏、点赞；不要复制旧会话令牌。旧 ChatGPT 身份不能直接在独立站登录，若原站有这类账号，需要在切换前为其准备经本人验证的账号关联流程。普通用户名密码账号可保留密码摘要继续登录。

在手机微信、手机浏览器和第二台电脑测试匿名查看、注册、发帖及回复，再交付新网址。迁移期间原站继续保留，最终切换时需短暂停写、导出最终快照并核对行数，避免迁移窗口丢失新增帖子。

## 本地运行

需要 Node 22.13 或更新版本。

```sh
npm install
npm run build
npm test
DB_PATH=./data/forum.sqlite PORT=3000 npm start
```

SQLite 自动执行 migrations 中的增量建表文件。数据库、用户内容、密码摘要、会话和找回码均不得纳入版本控制。持久磁盘之外仍需定期数据库备份。
