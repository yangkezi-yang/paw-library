# 百无禁忌社区：Render 免费试用版

“生活那点事”板块现改名为“编剧那点事”，已有帖子由增量迁移保留。旧板块链接兼容新名称。登录后点击右上角昵称，可在“我的社区名片”上传或更换头像、修改昵称并点击“保存资料”。头像自动居中裁成方形；支持 JPG、PNG 和 WebP，原图最大5MB。服务端再次校验并转成256像素 JPEG，保存在 PostgreSQL 中，重启不会丢失。头像显示于导航、帖子列表、主帖和回复；修改后旧内容同步显示新头像。可以恢复默认猫咪头像。

马卡龙猫爪界面、兴趣板块、搜索、匿名浏览、发帖、引用回复、点赞、收藏、用户名密码注册、登录、找回码及昵称管理均已移植。前端和 API 在独立 Node 服务内运行，不代理原站，不依赖 chatgpt.site。

## 免费部署

使用 Render 免费 Web 服务和独立免费 PostgreSQL 数据库。数据库不会随 Web 服务重启丢失，但 Render 免费数据库只有 30 天有效期。免费 Web 服务闲置 15 分钟后会休眠，下次打开可能等待约 1 分钟。免费额度用尽后服务可能暂停，后续升级需要另行决定。

代码位于 paw-library 的 baiwujinji-render 分支、forum-render 目录，main 分支资料站保持原样。分支根目录 render.yaml 仅创建新的免费社区服务，通过 fromDatabase 引用已存在的 baiwujinji-community-free-db 免费数据库，不创建收费磁盘或收费数据库。

构建命令：`npm ci --no-audit --no-fund && npm run build`。启动命令：`npm start`。健康检查：`/healthz`。DATABASE_URL 由 Render 内部注入，不写入源码。

## 数据迁移

原站数据经私密运行环境变量 MIGRATION_SNAPSHOT 导入，整个导入在一个事务中执行，只执行一次。数据库初始化在端口监听前完成。保留账号密码摘要、作者 ID、帖子、回复、收藏、点赞，不复制旧登录会话。不得把数据库备份、连接串、密码摘要、找回码或会话令牌提交到公开仓库。

旧 ChatGPT 登录身份不能在新站直接登录；普通用户名密码账号可以保留密码继续登录。原站旧内容仍可浏览，新发内容需要在新站免费注册。切换时应检查原站最终快照，避免遗漏迁移窗口的新内容。

## 验证

本地使用实际 PostgreSQL 引擎 PGlite 验证 PostgreSQL 兼容性及重启持久化，也保留 SQLite 本地开发路径。测试覆盖匿名浏览、注册、发帖、回复、收藏、点赞、跨站拒绝、重启后数据和会话保留、退出、重新登录和找回密码。上线后仍需实际手机微信测试访问。

```sh
npm ci
npm run build
npm test
TEST_PG=1 npm test
```

线上启动必须有 DATABASE_URL；禁止将 Render 免费服务的临时本地 SQLite 作为用户数据库。SQLite 路径在 Render 中仍会拒绝未验证的磁盘。

## 回复与引用通知

登录后右上角铃铛显示未读消息。别人回复自己的帖子或引用自己的评论时，生成站内通知；引用通过原评论 ID 定位收件人，服务端校验其属于当前帖子。同一条回复发给同一个人仅一条通知，引用优先；自己的操作不会通知自己。通知与回复在同一事务中写入。

点击消息标记已读，并跳到正确页码的对应回复，目标楼层会高亮。支持全部已读、消息分页。消息只对收件人开放，帖子或回复删除后不继续显示其通知。未读状态保存在数据库中，重新登录后仍保留。页面打开且可见时每20秒检查新消息，切回页面时立即检查。此功能是站内提醒，不发送短信、邮件或微信推送。

## 与前台联动的管理后台

访问 `/admin`，使用社区账号登录。首次由站点所有者使用单独交付的一次性设置码将当前账号绑定为唯一站长；服务端只配置设置码摘要。设置成功后初始化入口关闭。不得把设置码写进源码、网址或公开文档。

站长可分配管理员和版主。管理员可以管理内容、用户、板块、公告设置和查看日志；版主仅可管理帖子、回复及举报。所有管理接口都会重新校验权限。站长权限不可通过普通权限编辑移除，管理员不能限制站长或同级管理员。完整数据备份仅向站长开放，导出使用一致性只读快照并排除登录会话及初始化秘密。

内容管理支持搜索、筛选、置顶、加精、锁帖、移动板块、隐藏和恢复。管理隐藏独立于作者删除，恢复不会重新公开作者已删除的内容。隐藏内容及其相关通知不会继续向前台提供，已关联的引用会显示“引用的评论已不可见”。

用户管理支持限时或持续禁言、封禁、解除限制、修改昵称和移除头像。禁言在服务器上拦截发帖回复；封禁撤销所有会话并阻止登录和找回密码绕过封禁。

板块支持新增、改名、分组、排序、关闭前台显示及关闭发帖回复。前台导航和发帖选项来自同一份数据库配置，改名会更新原帖且保留旧链接。公告、公约、注册开关、发帖开关、发帖间隔、正文长度均由后台维护；前台页面可见时每30秒同步配置，服务器每次写入均按最新配置校验。

前台帖子和回复提供举报按钮；举报仅举报人和管理人员参与处理，不向其他访客公开举报人信息。后台可以处理或忽略举报并填写说明，也可以同时隐藏目标内容。举报内容只在后台查看，前台提交后提示已受理。

所有管理修改与操作日志一同提交。后台概览显示真实数据库统计。备份包含账号密码摘要等敏感资料，必须私下保管，不得提交到公开 Git 仓库。当前界面提供备份导出，导入恢复需另行执行并核对数据。

验证命令：`npm run build`，`node --test tests.mjs admin-tests.mjs`，`TEST_PG=1 node --test tests.mjs admin-tests.mjs`。
